# Doorvisor Mobile Demo

A mobile UI screen for **Doorvisor**, an AI real-estate assistant, built from the Figma design and implemented with React, TypeScript, Vite, and Tailwind CSS v4.

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This is a static Vite app and deploys to [Vercel](https://vercel.com) with zero configuration:

1. Import this repository at [vercel.com/new](https://vercel.com/new).
2. Vercel auto-detects the Vite framework preset (build command `npm run build`, output directory `dist`).
3. Click **Deploy**.
